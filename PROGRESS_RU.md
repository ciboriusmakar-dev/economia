# ECONOMIA 1.9.5 — статус готовности

Дата технической проверки: 15.11.2026.

## Краткий статус

- **Единый импорт:** реализован для CSV, TSV, XLSX, JSON-stat 2.0 и ZIP; также поддерживается пакетная обработка папки.
- **Контроль качества:** структура, пропуски, числовые значения, дубли строк/ключей, разрывы годовых/квартальных/месячных рядов, паспорта, SHA-256.
- **Межисточниковая сверка:** реализовано сравнение наблюдений по ключам и выявление конфликтов значений, единиц, валюты, ценовой базы и классификаций.
- **Независимая сверка:** реализован отдельный модуль сравнения прогнозов/расчётов с внешним эталоном; требует независимого опубликованного файла.
- **План испытаний:** определены входы, контрольные расчёты, метрики и условия PASS/FAIL для M01–M14.
- **Автоматические тесты:** 95/95 пройдено.
- **Пилотный импорт:** 4/4 имеющихся CSV обработаны без ошибок; итог `PASS_WITH_WARNINGS` из-за отсутствующих паспортов/части метаданных.
- **Полные исходные наборы OECD/Eurostat:** пока не получены.
- **Полное эмпирическое подтверждение M01–M14:** не выполнено.
- **Независимая внешняя репликация:** не выполнена; создан механизм для её проведения.

## Границы и оговорки

- Автоматическое определение единиц по заголовкам является подсказкой, не доказательством. Неизвестные единицы/классификации требуют паспорта.
- Разрывы периодов автоматически выявляются для стандартных годовых, квартальных и месячных форматов; нестандартные обозначения требуют настройки.
- XLSX читается по сохранённым значениям активного листа; формулы не пересчитываются.
- JSON-приёмник рассчитан на JSON-stat 2.0, не на произвольные JSON-документы.
- Сравнение источников допустимо только после согласования определений, периодов, единиц, валют, ценовой базы и классификаций.
- Критерии экономической значимости, валидности инструментов, параллельных трендов и корректности технологических коэффициентов требуют экспертной проверки.
