# Единый контракт данных ECONOMIA

## Обязательные поля набора

| Поле | Смысл |
|---|---|
| dataset_id | Уникальный идентификатор неизменяемой версии набора |
| source_id | Идентификатор первоисточника |
| records | Список записей в канонической структуре модели |
| origin | observed / synthetic / scenario / derived / forecast / estimate |
| data_mode | real или simulation |

Паспорт дополнительно должен содержать версию источника, время получения, период, географию, классификацию и её версию, единицы, валюту и ценовую базу, лицензию, атрибуцию, URL и SHA-256 исходного файла.

## Принципы

- Пропуск — отдельное состояние, а не ноль.
- Нулевое значение допустимо только если оно реально наблюдалось или следует из корректного преобразования.
- Флаги Eurostat/OECD сохраняются; оценочные и предварительные значения не смешиваются с окончательными без явной маркировки.
- Разные единицы, валюты, периоды, ценовые базы и классификации не объединяются без преобразования с документированным коэффициентом/таблицей соответствия.
- Синтетические данные используются только в `simulation` и тестах.
- Для каждого нормализованного набора сохраняется связь с исходным файлом и версия преобразования.

## Канонический формат наблюдения

`entity_id, indicator_id, period_start, period_end, value, unit, geography_id, currency, price_basis, classification, source_id, dataset_id, origin_type, status, quality_flags`.

## Проверки перед расчётом

1. Структура и обязательные поля.
2. Типы и конечность чисел.
3. Уникальность ключей наблюдений.
4. Допустимость отрицательных значений для конкретного показателя.
5. Согласование единиц и ценовой базы.
6. Непрерывность/частота периодов там, где она требуется моделью.
7. Полнота ключевых переменных и доля исключённых наблюдений.
8. SHA-256 и паспорт происхождения.
