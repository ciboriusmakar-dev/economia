# Публичный сайт ECONOMIA на GitHub Pages (бесплатно)

Раз в сутки GitHub сам скачивает данные Eurostat, пересчитывает панели и отчёты и обновляет сайт. Свой сервер не нужен.

## Один раз: запуск (с компьютера, 10–15 минут)
1. Зайдите на github.com → **New repository**. Имя, например, `economia`. Тип **Public** (для бесплатного Pages). Нажмите Create.
2. Распакуйте архив проекта. В репозитории нажмите **Add file → Upload files** и перетащите ВСЁ содержимое папки проекта, в том числе папку `.github` (она скрытая: в Проводнике включите «Показывать скрытые элементы»). Нажмите **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. **Settings → Actions → General → Workflow permissions → Read and write permissions → Save**.
5. Вкладка **Actions** → «Обновление данных и публикация сайта» → **Run workflow**. Через 5–15 минут сайт откроется по адресу `https://<ваш-логин>.github.io/economia/`.

Дальше обновление идёт само каждый день в 04:17 UTC (09:17 по Омску). Вручную: Actions → Run workflow.

## Как это устроено
- `update_data.py`: скачивает наборы из `site_config/datasets.json`, проверяет файл, сравнивает SHA-256, ведёт историю в `data/manifest.json`. Плохая загрузка не затирает прежнюю хорошую копию (прежние файлы хранятся в кэше GitHub).
- `build_site.py`: строит `site/` (главная, панели M01, отчёты M02, M03, M07, M09, таблица источников и версий).
- `.github/workflows/update.yml`: расписание и публикация. Перед публикацией выполняются тесты: если они не проходят, сайт не обновляется, а прежняя версия остаётся.

## Два режима
На главной и в каждом отчёте есть переключатель «Пользователь / Профессионал» (запоминается в браузере). Пользователь видит панели и отчёты; профессионал дополнительно видит версии данных, контрольные суммы, параметры расчёта и раскрытые технические подробности.

## Источники и лицензии
Eurostat и Всемирный банк (WDI: ВВП, инфляция). Условия проверены 17.11.2026 по официальным страницам и вынесены на страницу `licences.html` сайта; на каждой странице указан источник в виде, который просят источники. Исключена Великобритания (данные стран вне ЕС, ЕАСТ и кандидатов Eurostat разрешает только некоммерческое использование). Если сайт будет коммерческим, проверьте условия повторно.

## Что добавить набор данных
Добавьте объект в `site_config/datasets.json` и страницу в `build_site.py`.

## Ограничения (честно)
- Адреса Eurostat и сама цепочка GitHub Actions проверены на локальном подставном сервере, а не на живом GitHub. Первый запуск на GitHub стоит наблюдать.
- Статичный сайт: нет личных кабинетов и загрузки файлов на сервер. Своя загрузка CSV в панель M01 работает в браузере.
- Условия лицензий проверены один раз по официальным страницам (17.11.2026); они могут меняться. Данные Всемирного банка на живом соединении ещё не загружались.
- Расчёты автоматические; это не эмпирическое подтверждение моделей.
