# Ручная загрузка (то, что нельзя скачать скриптом одной ссылкой)

Скачивайте оригинальные файлы, не открывая и не пересохраняя их. Кладите в папку `raw/`.
После этого запишите строку в `provenance.csv` (название, URL, дата, период, единицы, лицензия).

## Блок 1 (M01–M06)

**PRODCOM ds-059358 / ds-059367 и Comext ds-045409** скриптом `fetch_all.py` не качаются: DS-наборы отдаются только через Comext API с фильтрами (страна, продукт, поток, период). Их берёт загрузчик `eurostat_api.py` / `acquire_full_datasets.py` из ECONOMIA 1.8.2 после того, как составлен проверенный список кодов PRODCOM/CN/HS.

| Модуль | Что скачать | Где | Примечание |
|---|---|---|---|
| M01 | Таблицы соответствия PRODCOM ↔ CPA ↔ CN/HS | Eurostat RAMON (ec.europa.eu/eurostat/ramon) | Только официальные correspondence tables |
| M01, M03, M11 | Comext `ds-045409` (DE как репортёр, 2008–2025) | Eurostat Comext, bulk download (`comext/COMEXT_DATA/PRODUCTS/`, ежемесячные файлы `full_v2_YYYYMM.7z`) | Файлы большие; выбирайте годы блоками |
| M04 | OECD STAN 2025, `DSD_STAN@DF_STAN_2025`, DEU | data-explorer.oecd.org → Export → CSV «full, with labels and codes» | Нужны: VALU, PROD, GFCF, CFC (амортизация), EMPN/HRSN, LABR, дефляторы. Запас капитала в STAN неполон — дополнительно Eurostat `nama_10_nfa_st` |
| M05, M06 | OECD IOT 2025: `IOTs_DOMIMP.zip`, `IOTs_TTL.zip`, `IOTs_VA.zip`, `IOTs_LEONTFT.zip` | oecd.org → ICIO / Input-Output Tables | Страна DEU, годы 2008–2022/23; файлы не распаковывать и не править |
| M05 | Destatis: Kostenstrukturerhebung (GENESIS 42251) | www-genesis.destatis.de | Экспорт CSV |

## Честные ограничения

- M08, M10, M12, M13 нельзя закрыть одними публичными выгрузками: нужен выбор события или данные предприятия.
- Запас капитала по отраслям публично неполон; потребуется оценка (метод непрерывной инвентаризации), и это уже расчёт, а не исходные данные.
- Для M02 инструменты нужно обосновать отдельно; в набор они не входят.
