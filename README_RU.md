## Что добавлено в 1.8.2

- Единый импорт CSV, TSV, XLSX, JSON-stat 2.0 и ZIP.
- Пакетная обработка папки с таблицами.
- Безопасное извлечение ZIP: защита от path traversal и ограничение размера распаковки.

- Паспорт набора данных с проверкой источника, версии, даты получения, лицензии, атрибуции, режима данных и хеша.
- Межисточниковая сверка по ключам с выявлением расхождений значений, единиц, валют, ценовой базы и классификаций.
- Независимая сверка с опубликованными эталонами: MAE, RMSE, MAPE и абсолютная ошибка; одинаковый источник не принимается как независимый эталон.
- Полная матрица эмпирических испытаний и текущих блокировок M01–M14.

## Быстрый импорт

```bash
python -m pip install -r requirements.txt
python economia_ingest.py path/to/file.csv --out data/intake
python economia_ingest.py path/to/archive.zip --out data/intake
python economia_ingest.py path/to/folder_with_tables --out data/intake
```

Подробности: `DATA_INTAKE_AND_VALIDATION_RU.md`. Шаблон паспорта: `DATASET_PASSPORT_TEMPLATE.json`.

## Независимая сверка

Заполните `INDEPENDENT_REFERENCE_TEMPLATE.csv` данными из отдельного опубликованного источника, не использованного для построения проверяемого результата:

```bash
python independent_validation.py predictions.csv references.csv --keys entity_id,indicator_id,period,geography_id --value value --abs-tol 0.01 --rel-tol 0.001
```

Допуски должны быть установлены до просмотра результата и соответствовать округлению/методологии источника.
