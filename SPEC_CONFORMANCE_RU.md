# Соответствие спецификации (rev. 1.0) — версия 1.9.5

Проверено только на синтетических данных (аналитические тесты). Эмпирической проверки на реальных данных НЕТ.

| Модуль | Статус | Что сделано | Честные пробелы |
|---|---|---|---|
| M01 Анализ товаров и товарных балансов | Реализован | Панель: производство, импорт, экспорт, потребление, баланс, самообеспечение, сверка с источником | Нет цен (нужны стоимостные данные Comext); нет производства PRODCOM (нужны таблицы соответствия) |
| M02 Спрос и рыночная активность | Реализован | Динамика, сезонность, связь с ценой и др. рядами | Эластичность — только описательная |
| M03 Анализ цен | Реализован | Индексы, инфляция, реальные/номинальные цены | Корзины и веса не строятся |
| M04 Производительность | Реализован | Труд, часы, капитал, ТФП | Запас капитала нужно задавать извне |
| M05 Себестоимость и затраты | Реализован | Структура затрат, себестоимость единицы, вклад статей в её изменение, эффект объёма и себестоимости, сравнение групп, пометка типа показателя (бухгалтерский / экономическая оценка / расчётное приближение) | Только по готовым статьям; нет оценки по ценам ресурсов |
| M06 Межотраслевой анализ | Реализован | Матрица A, обратная матрица Леонтьева, мультипликаторы, связи «назад» и «вперёд», импортная составляющая, эффект изменения конечного спроса, проверки балансов по строкам и столбцам | Нужны полные согласованные таблицы; реальных межотраслевых таблиц (OECD IOT) пока нет |
| M07 Макроанализ | Реализован | Рост, дефлятор, структура ВВП | Без эконометрики |
| M08 Причинный анализ | Реализован | Сравнение групп, разность разностей, контрольные переменные, кластерные ошибки, проверка параллельных трендов, плацебо, предупреждение «корреляция не доказывает причинность» | Нужно выбрать событие и группы; реальных данных нет |
| M09 Прогнозирование | Реализован | Базовые методы + проверка на скользящем начале | Не предсказание экономики |
| M10 Оптимизация производства | Реализован | Линейное и целочисленное программирование, теневые цены, загрузка мощностей, потребность в ресурсах, минимизация затрат, второй критерий (набор компромиссных планов) | Нужны данные о технологии и мощностях предприятия; многокритериальность — метод ограничений, без весов предпочтений |
| M11 Несколько рынков | Реализован | Сравнение цен и объёмов | — |
| M12 Запасы | Реализован | Оборачиваемость, EOQ, страховой запас, точка заказа | Нужны данные предприятия |
| M13 Логистика | Реализован | Кратчайшие пути, макс. поток, распределение | Нужна реальная сеть |
| M14 Риски | Реализован | Сценарии, чувствительность, интервалы | — |

Независимая сверка: `independent_check.py` сравнивает M07, M02 и M03 с процентами, опубликованными Eurostat (допуск 0,06 п.п., все три проверки пройдены на загруженных файлах).

Не сделано: веб-интерфейс с двумя режимами, ETag/планировщик обновлений, проверка лицензий, реальные данные.
