# Каталоги данных

- `raw/` — исходные полные файлы без преобразования; рядом сохраняются `.metadata.json` и SHA-256.
- `processed/` — нормализованные таблицы для конкретных моделей. Любое преобразование должно иметь скрипт и таблицу соответствия кодов.

Сейчас оба каталога пусты: загрузка в среде сборки заблокирована ошибкой DNS. Не помещать сюда синтетические данные под видом официальных.
